# reserva_aulas
Este programa ha sido creado por Gemini.Google.com.
Su objetivo es la gestión de varias aulas de informática, reservando los espacios.
Existen dos tipos principales de usuarios:
+ Cliente: puede solicitar la reserva o cancelarla
+ Gestor: confirma o rechaza la reserva, puede


## Empezar
Compilar en linux:
$ flutter run -d linux

crear el fichero apk:

$ flutter build apk
